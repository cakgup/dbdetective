# Oracle AVDF Training Simulator — GitHub Pages Edition

Static browser-only edition prepared from the DB Detective / AVDF training package.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload **all files and folders from this ZIP to the repository root** (do not upload the enclosing ZIP folder as a subfolder).
3. Commit/push to `main`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then Save.
7. Open the Pages URL after deployment completes.

## Static edition notes
- Day 1–5 catalog: 394 indexed labs.
- Progress is stored in browser local storage.
- AVDF console, SQL*Plus, OS terminal and AVCLI are simulated client-side.
- GitHub Pages cannot run the original Python/SQLite API. Real Oracle/Hybrid mode therefore remains unavailable in this edition.
- For full Python simulation semantics or real Oracle hybrid execution, use the original server edition instead.

This is a training simulator and is not an Oracle product.
